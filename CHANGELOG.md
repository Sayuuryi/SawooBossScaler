# Changelog

## [0.1.2.0]

### Settings
- Resize my target: try a size on any enemy, a striking dummy works, to check which size method works for you

### Fixes
- Bosses are put back to normal size when they stop being resized while still on the field
- The plugin still loads if enemy actions can't be read after a game patch; phases then follow casts and bosses showing up
- Putting bosses back when unloading is done on the game's thread

## [0.1.1.0]

### Bosses
- One size per phase: each phase has its own slider for all of its bosses
- Sizes for single bosses are under "Each boss" in phases with more than one boss

## [0.1.0.0]

### Bosses
- Pick a size from 10% to 200% for every boss in every phase of all seven ultimates
- Sizes change when the fight moves to the next phase and go back to normal after a wipe
- Set a boss to the same size in every phase, or every boss in a fight at once

### Settings
- Instant sizes, or a redraw through Penumbra if the instant option doesn't work for you
